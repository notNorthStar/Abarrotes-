# HU-02 y D-02 · Miguel · 28 de octubre de 2026

## Entrega

HU-02 incorpora escaneo por código + Enter, acumulación del producto repetido, aviso 404 y búsqueda manual por nombre. La cuenta permite cambiar cantidades y quitar renglones. El foco regresa al escáner al agregar, editar, quitar, terminar la captura de peso y confirmar una venta. Los productos KILO abren la captura existente de HU-03.

D-02 aporta [siete pantallas y cuatro alertas reales](../../prototipos/README.md), vinculadas con P-01–P-07 de [los casos de uso](../../diagramas/casos-de-uso.md).

## Validación real

- `npm test`: **27 pruebas web y 101 pruebas API correctas**. Diez pruebas web nuevas cubren acumulación, edición, validaciones y eliminación del carrito.
- `npm run lint`: ESLint y tipos correctos.
- `npm run build`: API y web compilan correctamente.
- Edge con teclado: escanear dos veces el mismo código deja un único renglón con cantidad 2; tres lecturas consecutivas se procesan en orden y no se pierden.
- Editar piezas a `1.5` y kilos a `0.0001` muestra error y conserva los totales. Quitar una fila recalcula la cuenta.
- Un código inexistente muestra aviso; la búsqueda de `Agua Ciel` permite agregarlo manualmente.
- Escanear el código de jitomate abre el peso; `750 g` produce `0.750 kg` y `$21.68`. No se agrega automáticamente un kilo.
- Cuenta de 3 Coca-Cola, 1 Agua Ciel y 0.750 kg de jitomate: **$89.18**. Pago de $1 rechazado sin registrar venta. Pago mixto de $70 en efectivo y $29.18 en tarjeta: **$10 de cambio**.
- El servidor registra una venta por $89.18 y el efectivo esperado aumenta **$60 netos**. Se confirma el corte y cierre sin diferencia. Después de cobrar, el campo de escaneo vuelve a tener foco.
- Sin errores JavaScript en estos recorridos. Los datos y operaciones son de la base local de ejemplo. Se simuló el lector USB mediante teclado; no se probó hardware físico.

## Explicación de archivos

- `carrito/Escaneo.tsx`: consulta productos por código y por nombre; serializa las lecturas para conservar su orden; deriva los productos por kilo a la captura de peso.
- `carrito/FilaProducto.tsx`: muestra cada fila y permite actualizar su cantidad o quitarla. Un error no modifica la cuenta.
- `carrito/store.ts`: valida cantidades en las operaciones públicas y conserva dinero como Decimal/texto, reutilizando las reglas de HU-03.
- `carrito/store.test.ts`: diez escenarios de acumulación, cálculo y rechazo de cantidades inválidas.
- `VentaPage.tsx`: conecta escaneo, tabla, granel y cobro existentes; restaura el foco al vaciarse la cuenta.
- `granel/Granel.tsx`: recibe el producto escaneado y devuelve el control al terminar o cancelar, sin cambiar el cálculo de HU-03.
- `docs/prototipos/`: catálogo, pasos de reproducción y once imágenes PNG.

No se modifican caja, cobro, autenticación, alta de productos ni el schema de Sosa. Las tareas quedan listas para revisión por Sosa mediante PR contra `develop`; no se marcan como integradas antes de su aprobación.
