## Específico de Claude Code

Comandos del proyecto (`.claude/commands/`):

| Comando | Para qué |
|---|---|
| `/hu HU-05` | Implementar una historia de usuario de punta a punta (plan → código → pruebas → PR) |
| `/setup` | T-00: crear el esqueleto del monorepo (solo Sosa, una vez) |
| `/daily` | Generar tu parte del daily scrum desde tus commits |
| `/revisar-pr 12` | Revisar el PR de un compañero contra los criterios de aceptación |
| `/estado` | Ver avance del sprint y puntos restantes |
| `/cierre-sprint` | Preparar review, retrospectiva, burndown y checklist del documento Scrum |

Usa plan mode para HU grandes (HU-05, HU-06, HU-03).
